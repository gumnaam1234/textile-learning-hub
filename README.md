
# Textile Industry Dashboard 🧵

A colorful textile industry web application developed using Streamlit and Python.

## Features

- Textile industry dashboard
- Production and quality metrics
- Monthly production charts
- Spinning department information
- Weaving department information
- Dyeing and finishing information
- Garment manufacturing information
- Editable production data
- Download production records as CSV
- Colorful user interface

## Technologies

- Python
- Streamlit
- Pandas
- Plotly

## Project Files

- App.py
- requirements.txt
- README.md

## How to Run

Install the required libraries:

    pip install -r requirements.txt

Run the application:

    streamlit run App.py

## Screen Colors

- Navy: #17324D
- Blue: #2878B5
- Teal: #19A7A0
- Gold: #F2B134
- Light background: #F3F7FA

## Note

The production figures are sample data for demonstration.
Replace them with real data when available.

## Deployment

Upload all three files to a GitHub repository.
Connect the repository to Streamlit Community Cloud.
Set App.py as the main file and deploy.
